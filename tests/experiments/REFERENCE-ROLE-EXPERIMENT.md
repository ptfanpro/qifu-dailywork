# 本机参照图角色试验（未通过，未接入产品）

## 假设和固定方案

整图通用描述 CLIP 未能可靠区分水碗、灯阵和带灯焰的纸张。本轮复用 `clip-role-reader.mjs` 中已校验的固定图像模型和完全相同的两视图 RGB 预处理，不下载模型，不把照片发送到外部。新试验使用人工逐张核对的参照图向量，不再依赖四类英文描述；没有修改模型权重。

参照库为三个完整日期的 55 张：前景纸张/牌位 45、灯阵 6、水碗全景 4。两视图各取余弦最近的三张参照图，只有各自三张同类、两视图也同类、且没有异类并列时才提出诊断候选。参数在读取测试日期结果前固定，没有按失败结果改成只取一个邻居。参照类别来自实际完整彩图核对，不来自数字文件名或过去的自动分类。

另一组四个完整日期的 72 张不参与参照库，按日期和源 SHA 排除交集。它们在源码/参照库冻结之后推理；人工只看完整图片标注可见角色，不看模型输出，再独立对照已保存预测。该划分不是跨寺院、跨设备或随机抽样保证；同一地点背景也可能相似，不能声称完全独立于历史开发。类别核对不核实纸面编号、PDF、打印修订或订单。

## 首轮结果

| 完整图人工可见角色 | 同类候选 | 错类候选 | 未确定 |
| --- | ---: | ---: | ---: |
| 纸张/牌位 | 56 | 0 | 2 |
| 灯阵 | 7 | 0 | 1 |
| 水碗全景 | 0 | 0 | 6 |

55 张参照和 72 张测试图的向量读取共 53.677 秒，0 读取异常，所有原件前后哈希保持。63 个同类候选不是 63 张福单已正确赋号；九项未确定包括全部供水全景，因此不能替换正式场景入口。很多水景的最近一张虽同类，但其余近邻混入纸张/灯阵；还有一张纸张的居中视图最近参照为水景，不能改用单一视图或单邻居制造通过。

逐张人工核对全部 127 张完整图，保存 22 张联系表的哈希；独立验证全部输入、参照标签、冻结源码和 72 个预测，并用保存向量重新计算全部预测，无新增模型轮次。照片、特征向量、人工角色、相近图片身份及报告只在本机专用 TEMP，不进 Git、不随迁移包分发。

首个启动命令误传相对运行库路径，在真实推理开始前失败；改用绝对路径后运行，失败目录保留。后续读取器在入口规范化路径。首轮外层 fingerprint 包含时间，只是轮次标识；内部 modelFingerprint 不含时间。后续源码另加入不含运行时钟、测试日期或测试标签的算法指纹测试；旧快照和失败结果不改、不重跑计数。

## 约束和回归

`reference-role-reader-regression.mjs` 的四项合成回归加入普通入口，涵盖独立日期/内容排除、人工审核要求、完整视图、有限向量、非法日期、单日期类别、并列/不一致、调用方数据修改、稳定算法身份和禁止业务权限。它们只验证代码与协议，不代表真实照片通过。

该试验只认识参照库里的三类，没有校准无关物体或全新场景的拒绝能力，不能把候选视为确定概率，也不能据它排除纸张、清除 OCR 相反观察或上传场景。正式产品三项显式场景语义反例仍失败，不能用这组角色专项覆盖。下一项替代方案须同时验证供水召回、前景纸张保护和真实灯阵，保留本轮失败作为开发材料，另外选择未用于调整的日期复核。

显式运行（先将脚本及其依赖冻结到独立树；全部路径为绝对路径）：

```text
node --test tests/experiments/reference-role-reader-regression.mjs
node tests/experiments/reference-role-replay.mjs PRIVATE_ROOT PRIVATE_MODEL_DIR FROZEN_APP_ROOT PRIVATE_CALIBRATION_JSON EVALUATION_DATE [...]
```

校准 JSON 的 `schemaVersion=1`、`manualWholeImagesReviewed=true`，`rows` 每项包含 `date`、`sha256`、`role`、`reviewed=true`。必须覆盖所选参照日期的全部库存照片，不能默默漏掉疑难项。输出目录包含参照特征、逐图特征与诊断、源码/模型/标签身份和完成报告；没有自动改名、上传或订单写入代码。
