# 场景入口不再回退到旧全局指标

2026-09-12。修复对象是缺少 `semanticRoleRead` 属性的底层调用路径，并非声称当前完整识别流程新发生了三个相同误判。完整识别结果本来就带该属性（含 unavailable/null），但旧缓存、部分调用者和诊断对象省略它时，旧函数会重新采用明暗、颜色、纸色连通块规则。

## 失败先行与实现

新增测试先在原实现复现：仅传入匿名全局指标的真实反例，被允许进入场景分支。正向的有来源绑定的供灯、供水证据测试当时已经通过。

正式 `isLikelyScene` 现在统一要求当前来源绑定的语义读数；省略属性与明确不可用同样不通过。完整编号、正文复核历史、编号读取失败/不完整/冲突等否决规则保持原顺序。没有降低模型阈值、修改模型或按缺图数量推断类别。

旧指标算法保留在 `diagnoseLegacySceneMetrics` 的显式诊断返回对象内：`mayAssign`、`maySkipCodeRecognition`、`mayAuthorizeUpload` 全为 false，不再是生产入口后备。原指标回归数据及其预期值保留，改为检查诊断结果，并逐例增加正式入口必须拒绝的断言。不能把旧诊断阳性称作识别成功。

- 三个已有安全反例：正式入口错误决定 0；旧算法错误提示仍显示 3，没有删例、改标签或掩盖。
