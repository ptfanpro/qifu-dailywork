# Original-crop alternate-model / actual-body review

Candidate engineering validation, 2026-09-12. Not annual, online or release
acceptance. Version remains 9.6.8-rc.2; fixed launcher, default photo/PDF dates
and manual CAPTCHA behavior are unchanged.

## Reproduced design gap

The June 10 baseline produced 11 assignments from 21 photos. All ten residual
code cases were rejected before the positive body collector. Some had a correct
complete observation and distinct actual page content, but any credible model
disagreement prevented collecting that corroboration. The blanket contrast
replacement was already rejected: it made one actual 186 code consistently
look like 188. Neither higher confidence nor more agreeing crops proves identity.

This change adds a separate, bounded evidence path for original-code model
disagreement. It does not remove raw contrary strings, alter the first reader,
weaken existing fast-path thresholds, fill missing numbers or select a PDF's
expected answer. It proves only local page correspondence, never upload or
online-order completion.

## Required conjunction

- Only fresh unresolved first-pass audits with complete original two-engine
  coverage qualify. Prior physical/body reviews, incomplete scans, native-scale
  contrary evidence and previously claimed visible-number conflicts cannot be
  silently cleared.
- Use the already packaged pinned Chinese recognition model to read BOTH
  original paddings of EVERY original code-bearing detector region (at most
  four regions). Pixel crops remain original; no contrast replacement, new
  detector search or expected-code-guided crop is used. Both paddings are
  views, not independent engines. Chinese and English Paddle models also are
  not claimed to be independent model families.
- Supplemental reports bind photo bytes, complete original read, crop bytes,
  model and all returned full/partial codes. An immutable process-local seal
  rejects copied, serialized, mutated or wrong-source reports. No report itself
  can assign a number or erase a conflict.
- The supplemental model must produce exactly one credible complete code,
  matching the business prefix, in two distinct original crops of the SAME
  detector region at confidence >= 0.85. At least one original engine must
  already have observed that same full code in that region above its existing
  threshold. All credible original alternatives must be in that same region
  and differ by at most one edit. Another-region code, a partial tail, wider
  disagreement, or both original engines agreeing at both paddings on an
  opposite complete code remains a veto. This yields only a candidate.
- Read the complete current physical PDF corpus and candidate photo content.
  Existing contrary/ambiguous-body checks remain. A candidate needs either two
  distinct, page-specific whole fields (>=4 Han characters each), both observed
  in paired views, or the existing strict source-bound positioned-field join.
  Shared names, a best similarity score, or a PDF slot left over do not qualify.
- Preserve the entire original audit/read, retain live authorization bound to
  the supplemental report, and rehash physical photo/PDF sources after review.
  Existing safe-plan isolation, JPEG transaction and exact receipt/restart
  checks remain mandatory. The new module is included in the source fingerprint.
