# 同名牌位：正文位置取证与组合字段试验

2026-09-11。本轮没有改号、处理业务原图或上传。仍未完成年度冻结验收及发布。

## 已确认的缺口

3 月 4 日两个未决牌位的姓名早已被原中文模型读出，但相同姓名也出现在当天其他普通福单页面。仅按全批唯一的单个文本字段寻找正文证据，会留下未决；不能把共用花边当作页面身份。原正文接口输出合并后的文字而不保留检测区域，无法检验姓名与牌位文案是否位于同一张纸及对应位置。

`src/chinese-body-reader.mjs` 新增显式 `includePositions` 选项，默认关闭。每个视图可保存原始 regionIndex、归一化区域、实际像素裁剪（含竖排旋转）、识别文本、置信度及原图尺寸。既有文本、顺序、置信度 .65、横排 300 / 竖排 80 上限和失败记录不变；重复文本仍保留各自的位置。位置不是前景主体、页码或订单绑定证明。正式判定入口本轮尚未启用该选项。

新增 `tests/positioned-body-reader-regression.mjs` 在实现前因缺失接口失败，实现后通过；覆盖相同裁剪字节、原索引、横竖两种布局、低置信过滤、读取失败、重复字段、空白、输出不引用可变区域及截断上限，并纳入普通测试入口。

## 实际只读验证

- 以新接口实际重读当天 16 页 PDF 及 16 张有编号照片，128 个视图与原保存观察的所有旧字段逐项相等，变化 0。约 131.958 秒；位置记录来自同一次读取，不另跑一个 OCR 模型。20 张输入照片、4 个 PDF 的字节哈希及该轮识别源码指纹前后均一致。
- 识别源码指纹：`7ede0bebd65b9e81975e891f00384d9d34a2cb072cc42f1f3ca2a61abc07f323`。这是字段读取兼容性验证，不是新完整处理计划、年度准确率或订单验收。
- 两张牌位各与完整的 16 页 PDF 做固定 `printed-ink` 版式几何比对，共 32 组，约 77.437 秒。产生 4 个完整印刷版式提议，覆盖两张照片；其他页面没有完整提议。两个 PDF 页模板相同，因此每张照片都对应两个版式提议，不能将 4 个提议计作 4 张成功。
- 实际姓名与牌位文案检测框都位于特征匹配的支持凸包内。两张照片的姓名/牌位文案投影框交并比分别约 .737/.858 与 .769/.833。不是用编号答案选择的框，也不是把投影外包框当成物理纸边。
- `positioned-field-probe.py` 仅为离线组合字段假设：同一个检测区域在同布局两视图中完整读出同一字段、无重复同字段位置、投影框多数重叠、位于实际支持凸包内，且至少两个完整字段的组合在全部 PDF 正文中唯一。字段逐项保留，不拼接为新姓名。纯花边、共用文案和单独姓名不够。
- 实际两张牌位分别得到一个唯一组合候选；交换对应 PDF 的完整正文后，均不再保持原页面候选。所有 `mayAssign` / `mayClearCodeConflict` 为 false，未写入业务计划。该诊断的 .5 几何交并比是试验标准，尚非跨日期校准后的生产阈值。

12 项显式 Python 生成数据测试通过，涵盖同名普通单、同名同模板重复、背景移位、重复位置、单视图、局部支持、其他页面读取失败、位置/文本不一致、镜像、多行文本及页面身份。普通 Node 套件 198 项和新增断言模块通过；完整 Windows 回归在本机用户环境通过（首次沙箱运行跳过 DPAPI，随后完整本机重跑未跳过）。这 12 项 Python 测试须用隔离 OpenCV 显式运行，不包含在 198 项计数里。

```text
NODE tests/positioned-body-reader-regression.mjs
PYTHON -B tests/experiments/positioned-field-probe-tests.py
NODE tests/run-tests.mjs
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ui/Run-Tests.ps1
```
