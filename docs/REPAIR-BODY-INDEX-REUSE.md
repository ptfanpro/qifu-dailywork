# 当前 PDF 正文索引按批复用

2026-09-11。分支从 `0d1daf9` 建立；保留该提交的孤立 PDF OCR 噪声修复。不升级版本、不部署，默认日期、人工验证码和固定入口不变。

## 实测问题

同源码暖回放里，全部 118 项正文原始观察命中缓存后，正文阶段仍约 81 秒。进一步对 3 月 3 日 69 页 PDF、49 张照片的完整原始观察单独测量：正文比较耗时 130.207 秒，调用 SHA-256 10,631,502 次，没有重新 OCR。

原因是每张照片的四个视图都重新生成相同的 PDF 片段集合和频率，短字段索引也按照片重建。上述 81 秒来自更早正文规则，130 秒来自包含来源相互支持的新规则，不能把它们当作同一版本两次受控测量。

## 改动边界

- 在当前 PDF 可见内容与物理页身份完整验证后，只建立一次片段/短字段索引，供该批照片查询。
- 索引是本次函数调用内的独立快照，不是全局缓存、持久化判断或跨日期复用。调用方修改输入数组或之前返回结果，不能污染后续查询。
- 每张照片仍重新核验视图和所声明物理页，返回全新的完整结果；来源提取/配对、原始频率、相反内容、短字段、排序、阈值、失败记录均不变。
- 读取前后仍核验原照片/PDF 字节；索引建立后源文件变化会使整批先前“通过”失效。旧冲突历史不会被新索引清除。
