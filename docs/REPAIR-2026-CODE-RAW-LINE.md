## 实图证据与改动

先把此前模型有分歧及仍未确认的照片去重，查看 27 组实际编号裁图和更宽原图上下文。部分字形像素不足，视觉读数本身也有疑点；这不是前瞻盲测，不能用旧文件名、两个模型一致或人工猜读制造真值。独立中文模型试验不能直接替换第二引擎。

既有取消字符白名单试验已经失败，未重复。新试验固定使用已安装 Tesseract 的原始行模式 13、现有红通道 96 像素预处理、原两个边距和原字符白名单。在七个开发日期的 154 张已有编号区域照片上实际读取 308 个原裁图，保留所有完整码、相反码、低分和空读。它仍是同一个 Tesseract 引擎，不是第三个独立引擎；也不是未见过的测试集。

在原有单行及整段补读后仍只有空读/弱同码时，追加这一次固定复查：

- 原检测覆盖完整、没有错误或断尾、所有完整码一致，且首引擎达到原有双边距门槛，才允许进入。
- 已经确认、任意相反完整码（包括低分）、旧复核失败及超过四个编号区域，均不进入。
- 固定读取同一原区域的两个边距，最多四个区域。不改变通过阈值，不按 PDF 缺号选择答案。
- 保存完整 `rawLineReview` 回执与旧记录；完成后显式恢复单行模式。恢复失败销毁 worker，不能污染下一张图或 PDF。
- 复用记录时校验前两次复核已完成、恢复状态、配方、裁图及两个边距。缺失或篡改回执不能授权继续。
